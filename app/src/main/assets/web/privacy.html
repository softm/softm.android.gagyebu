가계부 개인정보처리방침

시행일: 2026년 10월 30일

1. 금융 문자와 알림 처리

사용자가 기능을 허용하면 카드 결제, 입금, 출금으로 보이는 금융 앱 알림과 이번 달 1일 이후의 기존 SMS 및 새 SMS의 발신 정보·본문·수신 시각을 단말에서 분석합니다. 금액과 금융 키워드가 함께 있는 내용만 거래 후보로 보관하며 광고, 인증번호와 OTP 문구는 제외합니다.

READ_SMS는 사용자가 ‘이번 달 금융 문자 분석’을 선택한 경우에만 요청하며 조회 기간을 이번 달 1일 이후로 제한합니다. RECEIVE_SMS는 권한 허용 이후 도착하는 새 금융 문자를 감지하는 데 사용합니다.

알림 접근과 SMS 권한을 허용하지 않아도 붙여넣기, CSV 가져오기와 직접 입력 기능을 이용할 수 있습니다.

2. 영수증 OCR

사용자가 선택한 영수증 사진은 Google ML Kit의 기기 내 OCR 모델로 날짜·금액·상호 후보를 추출합니다. 인식된 전체 문장은 웹 화면이나 서버로 전달하지 않고 필요한 후보만 입력 화면에 돌려주며, 사용자가 확인하기 전에는 거래로 자동 저장하지 않습니다.

3. 저장과 동기화

  • 금융 알림/SMS 원문과 파싱 결과는 앱 전용 SQLite에 저장하기 전에 Android Keystore AES-GCM으로 암호화합니다.
  • 비로그인 장부는 단말 웹 저장소에 보관합니다.
  • 사용자가 로그인 동기화를 이용하면 확인 후 저장한 거래와 첨부 영수증이 사용자별 Firebase Firestore/Storage에 저장될 수 있습니다.

4. 광고

금융 알림/SMS 원문, 파싱된 금액·사용처와 가계부 거래를 광고 타기팅에 사용하거나 광고 사업자에게 전달하지 않습니다. 앱은 Google Mobile Ads와 Google UMP를 사용하며, 광고 게재와 측정을 위해 광고 식별자, 기기·앱 정보, IP 기반 대략적 위치와 광고 상호작용 정보가 처리될 수 있습니다.

5. 권한 철회와 삭제

모든 권한은 Android 설정에서 철회할 수 있습니다. 가져온 후보는 확인 필요함에서 삭제할 수 있고, 설정의 데이터 초기화 기능으로 앱의 장부 데이터를 삭제할 수 있습니다.

6. 문의

개인정보 관련 문의는 Google Play 스토어에 표시된 개발자 연락처를 이용해 주세요.
