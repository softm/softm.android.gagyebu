# 개인정보 및 금융 알림 처리

## 수집 범위

앱은 사용자가 허용한 뒤 이번 달 1일 이후의 기존 SMS와 새로 도착한 알림 또는 SMS에서 다음 조건을 모두 만족하는 내용만 처리합니다.

- 원 단위 금액이 존재함
- 승인, 결제, 사용, 입금, 출금, 이체, 송금, 취소, 환불 중 하나가 존재함
- 광고 또는 인증번호/OTP 문구가 아님

READ_SMS는 사용자가 ‘이번 달 금융 문자 분석’을 선택한 경우에만 요청하며, 조회 기간을 이번 달 1일 이후로 제한합니다.

영수증 사진을 선택하면 Google ML Kit의 기기 내 OCR 모델로 날짜·금액·상호 후보를 추출합니다. OCR 결과는 자동 저장하지 않고 사용자가 입력 화면에서 확인합니다.

## 보관

- 캡처 원문과 거래 파싱 결과는 앱 전용 SQLite에 저장되기 전에 Android Keystore AES-GCM으로 암호화됩니다.
- Android 자동 백업과 기기 간 데이터 전송에서 캡처 데이터베이스를 제외합니다.
- 캡처는 사용자가 앱 설정에서 삭제하거나 앱 데이터/앱 자체를 삭제할 때까지 해당 단말에 유지됩니다.
- 사용자는 앱 설정에서 캡처 원문 전체를 삭제할 수 있습니다.
- 캡처를 지워도 사용자가 이미 확인하여 가계부에 보관한 거래는 유지됩니다.

## 전송

- 캡처 원문은 Firebase 또는 다른 서버로 전송하지 않습니다.
- 가계부에 가져올 때는 날짜, 금액, 사용처, 선택된 자산·분류와 짧은 출처 설명만 웹 장부로 전달합니다.
- 기존 가계부에서 Firebase 동기화를 구성한 경우 사용자가 확정하거나 저장한 거래 데이터는 해당 사용자의 Firestore 장부로 동기화될 수 있습니다.

## 광고

- 앱은 Google Mobile Ads 및 Google UMP를 사용하며, AdMob 광고를 불러오지 못한 경우에만 Kakao AdFit 배너를 요청할 수 있습니다.
- 광고 SDK는 광고 게재, 빈도 제한, 부정 사용 방지, 측정 및 동의 처리를 위해 광고 식별자, 기기·앱 정보, 대략적인 위치(IP 기반), 광고 상호작용 정보를 처리할 수 있습니다.
- 금융 알림/SMS 원문, 파싱된 금액·사용처, 가계부 거래, 계정 정보는 광고 요청이나 맞춤 광고 타기팅에 사용하거나 광고 사업자에게 전달하지 않습니다.
- 관련 지역에서는 Google UMP 동의 화면을 제공하며, 필요한 경우 앱 설정의 **광고 개인정보 설정**에서 선택을 다시 변경할 수 있습니다.
- Android 설정에서 광고 ID를 재설정하거나 삭제할 수 있습니다.

## 권한 철회

- 알림 접근: Android 설정 → 특별한 앱 접근 → 알림 접근
- SMS 및 알림 표시: Android 설정 → 앱 → 가계부 → 권한/알림
- 앱 데이터 전체 삭제: Android 설정 → 앱 → 가계부 → 저장공간 → 데이터 삭제
