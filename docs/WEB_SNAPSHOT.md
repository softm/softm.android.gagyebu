스냅샷에는 원본 저장소의 당시 로컬 구현 변경도 포함되어 있습니다. Android 통합을 위해 app.js에는 WebMessage 브리지와 자동 가져오기 흐름, styles.css에는 권한 설정 UI 스타일이 추가되었습니다.
