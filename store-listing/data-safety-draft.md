# Google Play 데이터 보안 답변 초안

Play Console의 현재 질문 문구에 맞춰 최종 제출 전에 다시 확인합니다.

## 앱이 직접 처리하는 금융 메시지

- 금융 앱 알림과 사용자가 선택적으로 허용한 이번 달 기존 SMS 및 새 SMS는 단말에서만 처리합니다.
- 원문과 파싱 결과는 앱 전용 SQLite에 Android Keystore AES-GCM으로 암호화해 저장합니다.
- 원문·금액·사용처·거래 내역을 개발자 서버나 광고 사업자에게 전송하지 않습니다.
- 앱 설정의 **Android 감지 원문 전체 삭제**, Android 앱 데이터 삭제 또는 앱 제거로 삭제할 수 있습니다.
- 사용자가 선택한 영수증 사진과 OCR 결과는 기기에서 처리하며, 사용자가 거래에 첨부하고 로그인 동기화를 사용하는 경우에만 사용자별 Firebase Storage/Firestore에 저장될 수 있습니다.

따라서 단말 밖으로 전송되지 않는 금융 메시지와 거래 정보는 Play 데이터 보안 양식의 “수집”에서 제외하는 방향으로 답변하되, 최종 양식의 정의와 예외 문구를 재확인합니다.

## 광고 SDK 관련 보수적 답변

Google Mobile Ads/UMP 및 활성화 후 Kakao AdFit가 다음 데이터를 광고 게재, 측정, 빈도 제한, 보안·사기 방지 목적으로 처리할 수 있습니다.

| 데이터 유형 | 수집 | 공유 | 목적 | 필수 여부 |
|---|---:|---:|---|---|
| 기기 또는 기타 ID(광고 ID 포함) | 예 | 예 | 광고, 분석, 보안·사기 방지 | 광고가 표시되는 앱 사용 시 처리 |
| 앱 상호작용(광고 노출·클릭 등) | 예 | 예 | 광고, 분석 | 광고가 표시되는 앱 사용 시 처리 |
| 앱 정보 및 성능/진단 정보 | 예 | 예 | 분석, 앱 기능, 보안·사기 방지 | SDK 동작 시 처리 |
| 대략적 위치(IP 기반 추정 가능) | 예 | 예 | 광고, 분석, 보안·사기 방지 | SDK 동작 시 처리 가능 |

- 전송 중 암호화: 예(광고 SDK의 HTTPS 통신)
- 사용자에게 삭제 요청 방법 제공: 앱 로컬 데이터는 앱 설정/Android 설정/앱 제거로 삭제
- 계정 생성: 현재 Android 앱의 Firebase 로그인 설정이 비활성화되어 있으므로 필수 계정 없음
- 어린이 대상 앱: 아니요

광고 SDK의 최신 공개 데이터 공개 문서와 Play Console에서 표시하는 실제 질문을 기준으로 제출 직전에 항목을 확정합니다.
